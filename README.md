# LexCorp

> Enterprise corporate governance & entity management platform. Надежная архитектура и современные практики разработки, готовые к использованию в production-среде.

## 🎯 О проекте и его задачах
LexCorp — это платформа для автоматизации корпоративного управления (corporate governance) и ведения реестра юридических лиц. Главная цель системы — избавить корпоративных секретарей и юристов от рутины, минимизировать комплаенс-риски и обеспечить прозрачность процессов принятия корпоративных решений. 

Система закрывает ряд важных enterprise-требований, объединяя бизнес-логику и современные технологии:

* **Управление структурой компаний и заседаниями:** ведение реестра юридических лиц, подготовка повесток и резолюций. Это нужно для надежной, быстрой обработки бизнес-сценариев и работает на **FastAPI** с асинхронным **SQLAlchemy 2.0 (PostgreSQL)** в рамках строгой Clean Architecture.
* **Защита корпоративных данных:** аутентификация и строгий контроль сессий. Это нужно для исключения подделок токенов или алгоритмических уязвимостей и работает на криптографическом стандарте **PASETO v4.local** (вместо устаревшего JWT) в связке с **bcrypt**.
* **Контроль сроков и фоновые процессы:** мониторинг истекающих доверенностей (PoA), дедлайнов по отчетности и автоматическая сборка пакетов документов к заседаниям (board packs). Это нужно для предотвращения юридических рисков и работает на **Celery** с брокером **Redis**.
* **Автоматизация рутины с помощью AI:** генерация черновиков протоколов заседаний на основе утвержденных повесток. Это нужно для ускорения работы с документами при строгом сохранении коммерческой тайны и работает на изолированном локальном инстансе **Ollama** с применением **LangChain**.
* **Аудит и прозрачность (Observability):** детальное логирование действий, сбор метрик работы системы и трейсинг запросов. Это нужно для полного соответствия стандартам отказоустойчивости и аудита инцидентов и работает на **OpenTelemetry**, **Prometheus**, **Loki** и **Grafana**.

## 🚀 Быстрый запуск
Для удобства проект можно развернуть одной командой. Этот шаг автоматически создаст `.env` файл, поднимет всю инфраструктуру в Docker, дождется готовности базы данных и применит миграции:

```bash
git clone <repo>
cd LexCorp

# Запуск Docker-стека и инициализация базы данных
make setup
```

После успешного старта будут доступны следующие сервисы:
* **Swagger UI:** http://localhost:9100/docs
* **Grafana:** http://localhost:9000 (учетные данные: admin/admin)
* **Flower:** http://localhost:9555

*(Опционально) Запуск локальной LLM (Ollama) для работы AI-модулей:*
```bash
docker compose --profile ai up -d
make ollama-pull
```

## 💻 Локальная разработка и тестирование
Для комфортной работы над кодом и запуска тестов вне Docker, пожалуйста, используйте следующие команды:

```bash
# 1. Создание виртуального окружения (.venv для Python 3.12+) и установка зависимостей
make install

# 2. Запуск тестов (pytest)
make test

# 3. Полная проверка качества кода (линтеры Ruff, проверка типов Mypy и pytest)
make check
```

## 🧰 Основные команды (Makefile)
Список полезных команд для управления проектом:
```bash
make up         # Запустить Docker-стек в фоновом режиме
make down       # Остановить контейнеры и удалить тома (очистить БД)
make migrate    # Применить миграции базы данных (внутри контейнера)
make logs       # Просмотр логов API в реальном времени
make shell      # Открыть bash-сессию внутри контейнера API
```

## 📁 Структура проекта
```text
src/
├── core/           # Конфигурация, DI-контейнер, безопасность, телеметрия
├── domain/         # Предметная область: сущности, Value Objects, кастомные исключения
├── application/    # DTO (Pydantic) и Application Services (сценарии использования)
├── infrastructure/ # Реализации репозиториев (PostgreSQL), Redis, Celery, AI-интеграции
└── presentation/   # FastAPI роутеры, обработчики ошибок и зависимости (Depends)
tests/
├── unit/           # Модульные тесты доменной логики и ядра
├── integration/    # Интеграционные тесты инфраструктуры (Redis, метрики)
└── e2e/            # Сквозные тесты API (с использованием httpx.AsyncClient)
```
